No ingress. Reach the service locally with:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "ohmywind-mcp.fullname" . }} 7860:{{ .Values.service.port }}
  curl http://127.0.0.1:7860/healthz

/mcp rejects any Host header not listed in config.allowedHosts (421); the
guard matches host:port, so add "localhost:*" there for port-forward use.

{{- if include "ohmywind-mcp.apiTokenSecretName" . }}

  Authorization: Bearer <token>
(e.g. `claude mcp add --transport http ohmywind <url>/mcp --header "Authorization: Bearer <token>"`).
{{- else }}

/mcp is open to any caller. Set auth.token (or auth.existingSecret) to
require a bearer token.
{{- end }}
